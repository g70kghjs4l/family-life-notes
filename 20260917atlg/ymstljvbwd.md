# 秋季手足口病高发期！市妇保院专家提醒：这些防护知识家长一定要掌握！

> 更新时间：2026-09-17 (UTC+8)

提到手足口病，大家都不陌生。这种疾病下半年的高发期为9-11月，传染性强，传播途径多，5岁以下儿童多见，极易在托幼机构等集体单位传播，极少数重症病例可导致死亡。

随着9月托幼机构、学校迎来新学期，感染可能性上升。宝爸宝妈们应该如何从容应对，预防、判断、护理手足口病呢？听听九江市妇幼保健院感染科专家怎么说！

**01 / 什么是手足口病？**

手足口病是由多种肠道病毒通过密切接触的一种急性发热出疹性传染病。临床以手、足、臀部及口腔出现斑丘疹和疱疹为主要表现，部分病例伴随发热，少数患儿可引起心肌炎、肺水肿、无菌性脑膜脑炎等并发症。

手足口病发病人群以5岁及以下儿童为主，6月龄以下婴儿因有胎传抗体的保护发病较少，从6月龄开始发病逐渐增加，**1-2岁儿童发病风险最高**。低龄儿童发病后得重症、死亡的风险更高。

**02 / 手足口病通过什么传染？**

手足口病主要通过密切接触病人的粪便、疱疹液、鼻咽分泌物、唾液及接触被其污染的手、毛巾、手绢、牙杯、玩具、餐具、奶瓶、床上用品等物品或环境而感染。患者发病后第一周传染性最强。

**03 / 如何判断孩子是否得了手足口？**

孩子是否得了手足口病，作为家长咱们一定要知道如何判断！

手足口病的主要症状包括：

1、手、足、臀部、臂部、腿部出现斑丘疹，后转为疱疹，疱疹周围可有炎性红晕，疱内液体较少。手足部较多，掌背面均有。皮疹数少则几个多则几十个。

2、发烧、口痛、厌食，口腔黏膜出现散在疱疹或溃疡，位于舌、颊黏膜及硬额等处为多，也可波及软腭，牙龈、扁桃体和咽部。

**04 / 孩子会多次得手足口病吗？**

手足口病绝大多数患者会对感染过的肠道病毒血清型产生保护性抗体，因此，感染同一肠道病毒血清型而重复发病的几率较低。但因多种肠道病毒血清型均可引起手足口病，且相互之间无交叉保护，因此，**同一儿童可能因感染不同肠道病毒血清型而多次发生手足口病**。

**05 / 手足口病能治好吗？**

手足口病轻症一般的病程是7-10天，它具有自限性，一般不需要特殊处理，只要它没有重症的表现，可以遵医嘱在家进行对症治疗。平时要让孩子多喝水、吃清淡的饮食，可以帮助孩子自愈。严重的手足口病并发症出现后，经过正规治疗一般都会康复，只有极少一部分的孩子可能因为救治不及时，病情发展非常迅速，还有其他一些原因的影响，有可能会出现死亡。

**06 / 手足口病如何家庭护理？**

孩子得了手足口病，家庭护理需要注意什么？

1、由于患儿口腔溃烂、疼痛，故饮食尽量清淡，以流质食物最宜，避免进食酸辣、燥热、肥腻、难消化之品。

2.注意个人卫生，保持口腔清洁，溃疡局部可用淡盐水抹拭，局部喷上喉风散或西瓜霜等。若口腔黏膜溃疡明显的可用思密达粉剂撒于创面，以促进局部黏膜的修复。

3、手足心疱疹**不可用**未经消毒的针挑破，应由其自行消退，以免继发感染。可外用炉甘石洗剂以敛疮止痒，如疱疹破溃者可用金霉素眼膏或百多邦软膏搽破溃处。

4、可适当配合饮食疗法，如以胡萝卜、马蹄、竹蔗煲瘦肉汤或竹叶卷心加冰糖煎水代茶等。

5、一旦患儿出现胸闷、气促、疲惫、喜叹息等症状，应警惕并发心肌炎的存在，须即往医院诊治。

6、若患儿突然呕吐、颈项强直，甚至四肢抽搐，为并发中枢神经系统感染的征象，应及时治疗，以免延误病情。

**07 / 预防比治疗更重要！**

想要预防手足口病，最重要的两个方面如下：

**按时接种疫苗**

**1**

以前得过手足口病的患儿，还是有可能会再次发病的。所以接种疫苗是预防手足口病的重要手段。

目前我们只有针对肠道病毒71型，即EV-A71型灭活疫苗，而该疫苗只能预防EV-A71感染的手足口病。所以，即便打了疫苗，孩子在面对其它型手足口病毒时，仍然还会得病。

但家长们要知道，EV-A71型病毒是导致手足口病重症、危重症死亡的最关键的一个病毒，其他病毒很少会导致重症。孩子接种疫苗后，可以大幅减少发病的机会，它的保护率能到90%，甚至更高。

**培养良好卫生习惯**

**2**

预防手足口病的根本，是要养成良好的卫生习惯。因为肠道病毒主要是通过密切接触传播的，所以想要预防手足口病的发生，我们需要注意以下几点：

1、注意手卫生，尤其在触摸口鼻前、进食或处理食物前、如厕后、接触疱疹/呼吸道分泌物后、更换尿布或处理被粪便污染的物品后，应用清水、洗手液或肥皂洗手。

2、打喷嚏或咳嗽时用手绢或纸巾遮住口鼻，随后将纸巾包裹好丢入有盖的垃圾桶。

3、不与他人共用毛巾或其他个人物品。

4、避免与患者密切接触，如接吻、拥抱等。

5、经常清洁和消毒（含氯消毒剂）常接触的物品或物体表面，如玩具、家具等，清洁后用含氯消毒液进行擦拭或浸泡消毒，作用30分钟后，用清水擦拭或冲洗干净。

6、手足口病流行期间尽量避免带孩子参加集体活动。

手足口病可防可治，重在预防，“洗净手、喝开水、吃熟食、勤通风、晒被子”，是预防手足口病的15字方针，大家牢记在心，养成良好的卫生习惯，就能有效的预防手足口病的发生。
