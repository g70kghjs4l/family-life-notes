# 试管婴儿 | 孕前和孕期微量营养素怎么补？

> 更新时间：2026-09-16 (UTC+8)

**孕前和孕期微量营养素究竟要补什么？补多少？快来看看您都做对了吗？**

**一：关于叶酸代谢基因检测**

妊娠前、妊娠期**不推荐常规进行叶酸代谢相关的基因检测**以及血清或红细胞叶酸浓度检测。

**二：关于血清铁蛋白检测**

****对有贫血高危因素者，可在首次产前检查时（妊娠12 周内最佳）检测血清铁蛋白水平。

**三：关于体重增长**

1. 妊娠前低体重［体重指数（BMI）<18.5 kg/㎡］妇女，推荐妊娠期体重增长11.0~16.0 kg；

2. 妊娠前正常体重（BMI为18.5~<24.0 kg/㎡）妇女 ，推荐妊娠期体重增长8.0~14.0 kg；

3. 妊娠前超重（BMI为24.0~<28.0 kg/㎡）妇女，推荐妊娠期体重增长7.0~11.0 kg；

4. 妊娠前肥胖（BMI≥28.0 kg/㎡）妇女，推荐娠期体重增长5.0~9.0 kg；

5. 妊娠前正常体重的双胎妊娠孕妇，推荐娠期体重增长16.7~24.3 kg；

6. 妊娠前超重和肥胖的双胎妊娠孕妇，娠期体重增长应相应减少。

**四：关于叶酸补充**

1. 无高危因素妇女，建议至少从妊娠前3个月开始至妊娠满3个月，每日补充叶酸 0.4~0.8 mg；可选择含叶酸、维生素 B12 及铁的复合维生素补充剂；

2. 既往存在胎儿神经管缺陷（NTD）妊娠史的妇女，建议至少从妊娠前1个月开始补充叶酸4 mg/d（因国内剂型原因，可补充 5 mg/d），至妊娠满 3 个月；

3. 对于叶酸缺乏相关的出生缺陷高风险人群，建议至少从妊娠前3个月开始补充叶酸0.8~1 mg/d，至妊娠满3个月；

4. 建议孕妇妊娠中、晚期可继续补充叶酸或含叶酸的复合维生素，并持续整个妊娠期；

5. 对于妊娠前超重或肥胖妇女，建议至少从妊娠前3个月开始至整个妊娠期每日补充含叶酸0.8~1 mg的复合维生素；

6. 建议双胎妊娠孕妇从妊娠早期开始每日补充叶酸 0.8~1 mg，直至整个妊娠期。

**五：关于钙、铁、维生素D补充**

1. 建议从妊娠中期开始每天至少补充钙剂600mg直至分娩。对于服用碳酸钙出现胃肠道不适的妇女，可选择有机钙来源的钙补充剂；

2. 孕妇在日常适当户外活动获得充足日照的基础上，建议选择含维生素D的钙补充剂；

3. 建议超重或肥胖的孕妇，妊娠期持续补充维生素D（400U/d）、铁和钙等多种微量营养素；

4. 建议双胎妊娠孕妇妊娠期每日补充维生素D 1000U、钙1000~2000 mg和铁30~60 mg。
